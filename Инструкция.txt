Audio Scheduler PRO
Полная инструкция по использованию программы

1. Назначение программы

Программа предназначена для:
- воспроизведения звуков по расписанию
- озвучивания очереди вызовов
- воспроизведения отдельного голосового сообщения
- генерации речи через VoiceMaker
- работы со списком сотрудников и их голосовыми файлами


2. Главное окно

В главном окне есть 2 основных блока:

Планировщик оповещений
- позволяет добавить аудиофайл в расписание на нужное время
- кнопка "Выбрать" выбирает файл
- поле времени задаётся в формате ЧЧ:ММ
- кнопка "Добавить" добавляет запись в расписание
- кнопка "▶/■" воспроизводит выбранный файл или останавливает воспроизведение
- кнопка "Удалить" удаляет выбранную запись

Очередь вызовов
- показывает текущий вызов и ожидающие вызовы
- верхняя строка обычно показывает текущий воспроизводимый вызов


3. Меню программы

Меню "Программа"
- "Убрать в трей" прячет программу
- "Сохранить и закрыть" завершает работу

Меню "Опции"
- "Настройки" открывает все настройки
- "Генератор" открывает окно AI-генератора речи
- "Сотрудники" открывает окно списка сотрудников


4. Настройки

Настройки разделены по вкладкам.


5. Вкладка "Аудио"

Раздел "Выбор аудио устройства"
- Планировщик: устройство для файлов расписания
- Очередь вызовов: устройство для обычных вызовов
- Голосовое сообщение: устройство для отдельного голосового сообщения
- Генератор: устройство для AI-генератора и предпрослушивания голосов

Раздел "Настройка громкости"
- Планировщик: громкость файлов из расписания
- Очередь вызовов: громкость обычных вызовов
- Звук уведомления: громкость сигнала уведомления
- Генератор: громкость воспроизведения AI-генератора

Важно по громкости голосового сообщения:
- громкость голосового сообщения находится во вкладке "Вызовы"
- значение 1.0 означает примерно ту же громкость, что и у "Очереди вызовов"
- значение меньше 1.0 делает голосовое сообщение тише вызовов
- значение больше 1.0 делает голосовое сообщение громче вызовов


6. Вкладка "Планировщик"

Раздел "Дни работы планировщика"
- можно выбрать, в какие дни активен планировщик

Раздел "Запуск программы"
- галочка "Запускать вместе с системой" включает автозапуск программы


7. Вкладка "Звук уведомления"

Здесь настраивается звуковой сигнал перед воспроизведением.

Что можно настроить:
- выбрать файл звука уведомления
- прослушать выбранный звук
- включить уведомление перед планировщиком
- включить уведомление перед очередью вызовов
- включить "Звук перед повтором" для повторного вызова клиента


8. Вкладка "Вызовы"

Раздел "Настройки вызовов"
- Файл данных: текстовый файл, который программа отслеживает для очереди вызовов
- Интервал (сек): интервал опроса очереди
- Повторный вызов клиента: включает повторное воспроизведение вызова по номеру авто
- Интервал повтора (сек): задержка между первым и повторным вызовом
- Скорость воспроизведения: влияет на скорость чтения номера авто

Раздел "Голосовое сообщение"
- Файл: отдельный аудиофайл голосового сообщения
- Громкость голосового сообщения: регулируется относительно громкости "Очереди вызовов"

Раздел "AI Генератор"
- API файл: путь к .txt файлу с API-ключом VoiceMaker
- Список сотрудников: путь к .txt файлу со списком сотрудников
- Язык произвольного текста: язык для произвольных текстовых сообщений в очереди
- Голос для произвольного текста: голос для таких сообщений
- Кнопка "Послушать": воспроизводит тестовую фразу выбранным голосом


9. Формат файла очереди вызовов

Программа поддерживает несколько сценариев.

Вариант 1. Обычный вызов по номеру авто
Файл состоит из троек строк:
1 строка: начало сообщения
2 строка: номер авто или текст в центре
3 строка: окончание сообщения

Пример:
1
А123ВС22
5

Такие вызовы читаются собранным аудио из папки audio.

Вариант 2. Произвольный текст
Если в файле только одна непустая строка, она воспринимается как готовый текст.

Пример:
Уважаемые клиенты, касса номер три временно не работает.

Такой текст озвучивается через VoiceMaker голосом из раздела "Голос для произвольного текста".


10. Голосовое сообщение

Голосовое сообщение это отдельный аудиофайл, который программа отслеживает отдельно от очереди.

Как работает:
- вы выбираете файл голосового сообщения в настройках
- если этот файл обновится, программа воспроизведёт его через очередь вызовов
- для него используется своё устройство и своя относительная громкость


11. Окно "Генератор"

Окно генератора используется для ручной генерации речи через VoiceMaker.

Поля:
- Язык
- Голос
- Текст
- Название файла

Кнопки:
- "Сгенерировать" генерирует и сразу воспроизводит текст
- "Сохранить в..." сохраняет последнюю генерацию как .mp3
- "Закрыть" закрывает окно

Горячие клавиши:
- Enter запускает генерацию

Важно:
- если текст, язык и голос не менялись, повторная генерация может использовать уже полученный результат без нового запроса


12. Окно "Сотрудники"

Это окно используется для ведения списка сотрудников и их голосовых файлов.

Что можно делать:
- просматривать список сотрудников
- добавлять сотрудника
- удалять сотрудника
- прослушивать голос сотрудника

Добавление сотрудника:
- введите Фамилию Имя
- нажмите Enter или кнопку "Добавить сотрудника"
- имя запишется в файл списка сотрудников
- программа сгенерирует .mp3 и сохранит его в папку audio/workers

Удаление сотрудника:
- выберите сотрудника в списке
- нажмите Delete или Command+Backspace
- или кнопку "Удалить"
- сотрудник будет удалён из списка и его аудиофайл тоже удалится

Прослушивание сотрудника:
- двойной клик по строке
- или выделить строку и нажать Пробел
- воспроизводится файл сотрудника из audio/workers
- используются устройство и громкость генератора


13. Работа сотрудников в вызовах

Если в средней строке вызова указано имя сотрудника и для него найден файл в audio/workers, программа воспроизводит файл сотрудника вместо чтения номера авто.

Файл сотрудника ищется в формате:
- Фамилия_Имя.mp3
- или Фамилия_Имя.wav


14. Повторный вызов клиента

Повторный вызов работает только для вызовов по номеру авто.

Как работает:
- если включена галочка "Повторный вызов клиента", номер авто проигрывается повторно
- пауза между первым и вторым чтением задаётся полем "Интервал повтора (сек)"
- если включена галочка "Звук перед повтором", перед повторным вызовом снова звучит уведомление


15. Скорость воспроизведения номера

Настройка скорости влияет только на номер авто.

Она не должна влиять на:
- голосовое сообщение
- сотрудников
- произвольный текст через AI
- начало и окончание фраз планировщика


16. Где хранятся данные программы

На macOS пользовательские файлы программы хранятся в папке:
~/Library/Application Support/AudioSchedulerPro/

Там обычно находятся:
- config.json
- schedule.json
- client_calls.log

Важно:
- если заменить schedule.json в корне проекта, расписание в программе может не измениться
- рабочий schedule.json находится именно в пользовательской папке программы


17. Для чего нужен schedule.json

Файл schedule.json хранит расписание планировщика.

Если вы добавляете или удаляете записи в главном окне, программа сохраняет их именно туда.


18. API файл VoiceMaker

API файл должен быть обычным .txt файлом.
В нём должна быть одна строка:

пример:
YOUR_API_KEY

или:
Bearer YOUR_API_KEY

Лучше использовать просто ключ без лишнего текста.


19. Список сотрудников

Это обычный .txt файл.
Каждый сотрудник указывается на отдельной строке.

Пример:
Иванов Иван
Петров Петр
Сидорова Анна


20. Горячие клавиши

Главное окно:
- Enter: добавить запись в расписание
- Delete: удалить запись
- Пробел: Play/Stop

Окно сотрудников:
- Enter: добавить сотрудника
- Delete: удалить сотрудника
- Command+Backspace: удалить сотрудника
- Пробел: прослушать сотрудника
- двойной клик: прослушать сотрудника

Окно генератора:
- Enter: сгенерировать речь


21. Если программа не читает голоса VoiceMaker

Проверьте:
- выбран ли API файл
- есть ли в нём корректный ключ
- работает ли интернет
- установлен ли certifi, если Python жалуется на SSL


22. Если программа не видит обновление расписания или настроек

Проверьте, что вы редактируете файлы в пользовательской папке приложения, а не файлы в корне проекта.


23. Если что-то не воспроизводится

Проверьте:
- выбрано ли правильное устройство
- не слишком ли низкая громкость
- существует ли нужный аудиофайл
- не повреждён ли файл


24. Краткий порядок первоначальной настройки

1. Открыть "Настройки".
2. Во вкладке "Аудио" выбрать устройства.
3. Настроить громкости.
4. Во вкладке "Звук уведомления" выбрать файл уведомления.
5. Во вкладке "Вызовы" выбрать файл данных очереди.
6. При необходимости выбрать файл голосового сообщения.
7. Указать API файл VoiceMaker.
8. Указать файл списка сотрудников.
9. Выбрать язык и голос для произвольного текста.
10. Проверить генерацию через окно "Генератор".


25. Рекомендации

- храните API ключ отдельно и не публикуйте его
- для сотрудников используйте единое написание Фамилия Имя
- если используете ручное редактирование файлов, делайте это при закрытой программе
- после крупных изменений настроек лучше перезапустить программу
