# Инструкция по Audio Scheduler PRO

Эта инструкция описывает только два основных действия:

- как сгенерировать новое оповещение;
- как добавить готовое оповещение в планировщик.

## Как сгенерировать новое оповещение

1. Откройте меню **Опции -> Генератор**.
2. Выберите **язык**, **акцент** и **голос**.
3. В поле **Текст** введите фразу, которую нужно озвучить.
4. В поле **Название файла** укажите понятное имя файла.
5. Нажмите **Сгенерировать**.
6. Прослушайте результат.
7. Если все звучит нормально, нажмите **Сохранить в...** и выберите папку, куда сохранить файл.

Лучше давать файлам понятные названия, чтобы потом их было легко найти в планировщике.

Примеры:

```text
Кофе-брейк Catherine.mp3
Комната водителей.mp3
Обед.mp3
```

## Как добавить оповещение в планировщик

1. В главном окне найдите блок **Планировщик оповещений**.
2. Нажмите **Выбрать** рядом с полем **Аудиофайл**.
3. Выберите готовый аудиофайл оповещения.
4. В поле **Время** укажите время запуска в формате `чч:мм`.
5. Нажмите **Добавить**.

После этого оповещение появится в списке **Расписание**.

Пример:

```text
09:50 | Опьянение.mp3
10:50 | Душ.mp3
12:00 | Обед.mp3
```

## Как проверить оповещение

1. Выберите нужную строку в расписании.
2. Нажмите кнопку воспроизведения.
3. Если звук играет правильно, оповещение настроено.

## Как удалить оповещение

1. Выберите строку в расписании.
2. Нажмите **Удалить**.

## Важно

- Расписание воспроизводится только в рабочий день.
- Рабочий или нерабочий день отображается справа над списком расписания.
- Если день нерабочий, оповещения из планировщика звучать не будут.
- Программа должна быть запущена, чтобы планировщик работал.
