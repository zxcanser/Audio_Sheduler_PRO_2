# Audio Scheduler PRO

Настольная программа на `Python + tkinter` для аудиооповещений: расписание, очередь вызовов, голосовые сообщения и генерация речи через сервис `VoiceMaker`.

Пользовательская инструкция: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md)

## Что умеет

- Проигрывает аудиофайлы по расписанию.
- Следит за текстовым файлом очереди и озвучивает новые вызовы.
- Собирает номера авто из записанных фрагментов `audio/digits` и `audio/lettrs`.
- Воспроизводит готовые файлы сотрудников из `audio/workers`.
- Озвучивает произвольный текст через `VoiceMaker`.
- Отслеживает отдельный файл голосового сообщения и ставит его в очередь при обновлении.
- Поддерживает разные аудиоустройства и громкости для расписания, вызовов, уведомлений и генератора.
- Может работать с локальным HTTP-интерфейсом для добавления вызовов в очередь.
- Запоминает настройки, расписание и положение окна.

## Быстрый запуск

```bash
python3 main.py
```

Минимальные зависимости:

```bash
pip install numpy sounddevice soundfile pillow certifi
```

Опционально:

```bash
pip install pystray pyobjc
```

`pystray` нужен для трея на Windows. `pyobjc` может понадобиться для интеграции с macOS. `tkinter` обычно уже входит в Python.

## Основная настройка

1. Запустите программу.
2. Выберите аудиоустройства и громкости.
3. Добавьте записи в расписание или выберите файл очереди вызовов.
4. При необходимости выберите звук уведомления и файл голосового сообщения.
5. Для генерации речи укажите API-ключ `VoiceMaker`.

## Очередь вызовов

Программа читает выбранный `.txt` файл и реагирует на его изменения.

Вызов по номеру авто задается блоком из трех строк:

```text
1
А123ВС22
2
```

Где `1` выбирает `audio/start_options/start_1.*`, номер собирается из фрагментов, а `2` выбирает `audio/end_options/end_2.*`.

Вызов сотрудника использует тот же формат, но во второй строке указывается имя:

```text
1
Ракович Сергей
2
```

В этом случае программа ищет `audio/workers/Ракович_Сергей.mp3` или `.wav`.

Произвольный текст задается одной непустой строкой:

```text
Просьба подойти к воротам номер три.
```

Такой вызов озвучивается через `VoiceMaker` выбранным голосом для текстовых сообщений.

## Голосовое сообщение

В настройках вызовов можно выбрать отдельный аудиофайл. Когда файл обновляется, программа автоматически добавляет его в очередь и воспроизводит через устройство вызовов.

Для голосового сообщения есть отдельная относительная громкость. Перед воспроизведением применяется мягкое шумоподавление.

## VoiceMaker

Генератор доступен в меню `Опции -> Генератор`.

Поддерживается:

- выбор языка, акцента и голоса;
- предпрослушивание;
- сохранение результата в `.mp3`;
- отдельный голос для текстовых сообщений из очереди.

API-ключ можно вставить как обычный ключ или в формате `Bearer ...`.

## Сотрудники

Окно сотрудников открывается через `Опции -> Сотрудники`.

Файл сотрудников содержит по одному имени на строку:

```text
Ракович Сергей
Цорник Павел
```

При добавлении сотрудника программа генерирует аудио через `VoiceMaker` и сохраняет его в `audio/workers`. При удалении сотрудника удаляется и его аудиофайл.

## Интерфейс вызовов

Если HTTP-интерфейс включен в настройках, программа поднимает локальный сервер.

- `GET /health` проверяет, что сервер работает.
- `POST /api/call` добавляет вызов в очередь.
- При включенном токене его нужно передавать в `Authorization: Bearer <token>`.
- `request_id` необязателен, но защищает от повторного воспроизведения дублей.

Пример текстового вызова:

```json
{
  "type": "text",
  "text": "Просьба подойти к стойке информации",
  "request_id": "call-001"
}
```

Пример вызова по номеру:

```json
{
  "start_choice": "1",
  "car_number": "А123ВС22",
  "end_choice": "2",
  "request_id": "car-001"
}
```

## Где хранятся данные

Пользовательские данные лежат вне папки проекта.

- macOS: `~/Library/Application Support/AudioSchedulerPro`
- Windows: `%APPDATA%\AudioSchedulerPro`
- Linux: `~/.audioschedulerpro`

Там хранятся `config.json`, `schedule.json`, `client_calls.log`, `error.log` и `app.lock`.

Старые `config.json` и `schedule.json` из корня проекта подхватываются автоматически при первом запуске.

## Структура проекта

- `main.py` — точка входа.
- `controller.py` и `controller_*.py` — логика приложения.
- `models.py` — модели данных и настройки.
- `repository.py` — загрузка и сохранение настроек/расписания.
- `services/` — воспроизведение, очередь, API, VoiceMaker, планировщик.
- `ui/` — интерфейс.
- `audio/` — аудиофрагменты, уведомления и сотрудники.

## Горячие клавиши

- `Enter` — добавить или обновить запись расписания.
- `Delete` — удалить выбранную запись.
- `Пробел` — воспроизведение или остановка на главном окне.
- `Enter` в окне сотрудников — добавить сотрудника.
- `Enter` в окне генератора — сгенерировать речь.

## Сборка Windows

Пример команды:

```powershell
pyinstaller --noconfirm --windowed --onefile --name "AudioSchedulerPro" --icon "ASP_icon.ico" --add-data "ASP_icon.ico;." --add-data "audio;audio" main.py
```

Готовый файл будет в `dist`.

## Важные заметки

- Папка `audio` обязательна для вызовов по номеру, сотрудников и сборки приложения.
- Для `VoiceMaker` нужен интернет и рабочий API-ключ.
- Если на macOS не загружаются голоса `VoiceMaker`, проверьте установку `certifi`.
- Звук уведомления не блокирует основное сообщение: если уведомление недоступно, вызов все равно воспроизводится.
