# Audio Scheduler PRO

`Audio Scheduler PRO` — настольная программа на `Python + tkinter` для озвучивания расписания, очереди вызовов и отдельных голосовых сообщений.

Проект поддерживает:
- планировщик аудиофайлов по времени
- очередь вызовов клиентов по текстовому файлу
- озвучивание номеров авто из заранее записанных фрагментов
- озвучивание сотрудников по файлам из `audio/workers`
- AI-генератор речи через `VoiceMaker`
- автоматическое воспроизведение отдельного голосового сообщения при обновлении файла

## Возможности

- Воспроизведение аудиофайлов по расписанию.
- Выбор отдельных аудиоустройств для:
  - планировщика
  - очереди вызовов
  - AI-генератора
- Отдельные громкости для:
  - планировщика
  - очереди вызовов
  - голосового сообщения
  - уведомления
  - генератора
- Звук уведомления перед:
  - планировщиком
  - очередью вызовов
- Повтор вызова по номеру авто:
  - второй прогон сообщения
  - настраиваемый интервал между повторами
  - опциональный повторный звук уведомления перед вторым прогоном
- Скорость воспроизведения только для номера авто, без влияния на остальную часть сообщения.
- AI-генератор речи через `VoiceMaker`:
  - выбор языка
  - выбор голоса
  - предпрослушивание
  - сохранение `.mp3`
- Отдельный голос для текстовых сообщений из очереди.
- Управление списком сотрудников:
  - хранение в текстовом файле
  - генерация файлов в `audio/workers`
  - удаление сотрудника вместе с его аудиофайлом
- Логирование вызовов в `client_calls.log`.
- Автозапуск вместе с системой.
- Запоминание позиции главного окна.

## Как работает очередь вызовов

Программа поддерживает несколько сценариев.

### 1. Обычный вызов по номеру авто

Файл очереди должен содержать блоки по 3 строки:

```text
1
А123ВС22
2
```

Где:
- первая строка — начало фразы (`start_...`)
- вторая строка — номер авто
- третья строка — конец фразы (`end_...`)

Для номера авто используются файлы из:
- `audio/start_options`
- `audio/end_options`
- `audio/digits`
- `audio/lettrs`

Если вызов содержит номер авто, сообщение может повторяться дважды с настраиваемым интервалом.

### 2. Вызов сотрудника

Если вместо номера во второй строке указано имя сотрудника, программа пытается найти файл:

```text
audio/workers/Имя_Фамилия.mp3
```

или `.wav`.

Пример:

```text
1
Ракович Сергей
2
```

Тогда вместо сборки номера будет воспроизведён готовый файл сотрудника.

### 3. Текстовое сообщение через AI-генератор

Если файл очереди содержит ровно одну непустую строку, она воспринимается как готовый текст для озвучивания через `VoiceMaker`.

Пример:

```text
Просьба подойти к воротам номер три.
```

Для таких сообщений используется отдельный голос, который выбирается в настройках `Вызовы`.

### 4. Отдельное голосовое сообщение

В настройках `Вызовы` можно выбрать аудиофайл голосового сообщения.

Если этот файл обновляется, программа автоматически:
- замечает изменение
- ставит сообщение в очередь
- воспроизводит его через устройство очереди вызовов

Для этого сообщения используется отдельная громкость и мягкое шумоподавление.

## AI-генератор речи

В меню `Опции -> Генератор` доступно окно генерации речи через `VoiceMaker`.

Возможности:
- выбор языка
- выбор голоса
- ввод текста
- воспроизведение результата
- сохранение результата в `.mp3`

Для работы нужен `.txt` файл с API-ключом.

Подходят оба формата:

```text
YOUR_API_KEY
```

или

```text
Bearer YOUR_API_KEY
```

## Сотрудники

В меню `Опции -> Сотрудники` доступно окно управления списком сотрудников.

Что умеет:
- загружать список сотрудников из выбранного `.txt`
- добавлять нового сотрудника
- автоматически генерировать для него `.mp3` через `VoiceMaker`
- удалять сотрудника из списка и удалять его аудиофайл

Файл сотрудников должен содержать по одному сотруднику на строку:

```text
Ракович Сергей
Цорник Павел
```

При генерации имя сохраняется как:

```text
audio/workers/Ракович_Сергей.mp3
```

## Структура проекта

Основные файлы:
- `main.py` — точка входа
- `controller.py` — основная логика приложения
- `models.py` — модели данных и настройки
- `repository.py` — загрузка и сохранение настроек/расписания
- `config.py` — пути к данным приложения

Папки:
- `services/` — сервисы воспроизведения, очереди, генератора, планировщика
- `ui/` — интерфейс
- `audio/` — аудиофрагменты, уведомления и сотрудники

## Где хранятся данные

Пользовательские файлы сохраняются не в корне проекта, а в папке данных приложения.

Обычно это:
- macOS: `~/Library/Application Support/AudioSchedulerPro`
- Windows: `%APPDATA%\\AudioSchedulerPro`

Там хранятся:
- `config.json`
- `schedule.json`
- `client_calls.log`

При первом запуске старые `config.json` и `schedule.json` из корня проекта автоматически подхватываются.

## Зависимости

Минимальный набор:

```bash
pip install numpy sounddevice soundfile pillow certifi
```

Опционально:

```bash
pip install pystray pyobjc
```

Пояснение:
- `numpy` — обработка аудио
- `sounddevice` — воспроизведение
- `soundfile` — чтение и запись аудиофайлов
- `pillow` — иконка окна
- `certifi` — корректная SSL-проверка для `VoiceMaker`
- `pystray` — системный трей
- `pyobjc` — может пригодиться на macOS

Также нужен `tkinter`. Обычно он уже входит в Python.

## Запуск

Из корня проекта:

```bash
python3 main.py
```

## Сборка в `.exe`

Пример команды для Windows:

```powershell
pyinstaller --noconfirm --windowed --onefile --name "AudioSchedulerPro" --icon "ASP_icon.ico" --add-data "ASP_icon.ico;." --add-data "audio;audio" main.py
```

После сборки результат появится в папке `dist`.

## Горячие клавиши

- `Enter` — добавить запись в расписание
- `Delete` — удалить запись
- `Пробел` — `Play/Stop` на главном окне

Дополнительно:
- в окне сотрудников `Enter` добавляет сотрудника
- в окне генератора `Enter` запускает генерацию

## Примечания

- Для `VoiceMaker` нужен рабочий доступ в интернет.
- Если не загружаются голоса `VoiceMaker` на macOS, проверь установлен ли `certifi`.
- Для сотрудников и вызовов по номеру используются файлы из папки `audio`, поэтому при сборке приложения её обязательно нужно включать в пакет.
- Голосовое сообщение очищается мягким шумоподавлением перед воспроизведением.

## Быстрый сценарий настройки

1. Запустить программу.
2. В `Опции -> Настройки` выбрать устройства и громкости.
3. Выбрать файл очереди вызовов.
4. При необходимости выбрать файл голосового сообщения.
5. Выбрать `.txt` с API-ключом `VoiceMaker`.
6. В `Опции -> Генератор` выбрать язык и голос.
7. В `Вызовы` выбрать голос для текстовых сообщений.
8. При необходимости заполнить список сотрудников через `Опции -> Сотрудники`.
