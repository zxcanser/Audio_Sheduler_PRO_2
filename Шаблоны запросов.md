


#API шаблоны запросов



*Чтобы оповещения отличали дубликаты, мы добавляем request_id, можно просто время системы туда слать.*
*Можно вообще не слать request_id тогда дубликаты будут проходить.*

*IP и порт будут другие.*

*Токен можем поменять в любой момент если это может понадобиться...*



**Существующие варианты запросов:**

1. Водитель автомобиля БЦЦЦББЦЦ пожалуйста, ...
(
	если end_choice=1 
		"пройдите к своему авто"
	если end_choice=2
		"пройдите в приёмку"
)

curl -X POST http://10.1.32.6:8765/api/call \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 7f12e7fd65a9bbbb566f8b626eac3ae0" \
  -d '{"request_id":"%%%","start_choice":"1","car_number":"БЦЦЦББЦЦ","end_choice":"1"}'


2. *Рандомный текст в генератор* (можно не добавлять в принципе, можно ограничить доступ)

curl -X POST http://10.1.32.6:8765/api/call \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer 7f12e7fd65a9bbbb566f8b626eac3ae0" \
  -d '{"text":"Рандомный текст"}'
